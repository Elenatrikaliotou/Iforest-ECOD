# Iforest-ECOD ο αλγόριθμος Isolation Forest (IForest) αντικαταστάθηκε επιτυχώς από τον αλγόριθμο ECOD (Empirical Cumulative Distribution Functions for Outlier Detection) χρησιμοποιώντας τη βιβλιοθήκη PyOD.
 Διαφορές
- isolation Forest: Βασίζεται στην απομόνωση των δειγμάτων μέσω τυχαίων δέντρων αποφάσεων. Εντοπίζει τις ανωμαλίες με βάση το πόσο γρήγορα απομονώνεται ένα σημείο.
- ΕCOD: Βασίζεται στην εκτίμηση της εμπειρικής συνάρτησης κατανοφής πιθανότητας (ECDF). Υπολογίζει την ασυνήθικότητα των παρατηρήσεων εξετάζοντας τα άκρα των κατανομών για κάθε χαρακτηριστικό ξεχωριστά.
- Γιατί λειτούργησε καλύτερα ο ECOD: Στα δεδομένα κίνησης δικτύου (network traffic), οι ανωμαλίες (όπως ξαφνικές αυξήσεις σε μεγέθη πακέτων ή ρυθμούς ροής) εμφανίζονται συχνά ως ακραίες τιμές στα μεμονωμένα χαρακτηριστικά. Ο ECOD εντοπίζει αυτές τις ακραίες τιμές με μεγάλη μαθηματική ακρίβεια χάρη στην ανάλυση ECDF.
- Σταθερότητα: Σε αντίθεση με τον IForest ,   οποίος περιέχει στοιχείο τυχαιότητας και μπορεί να δώσει ελαφρώς διαφορετικά αποτελέσματα σε κάθε εκτέλεση ο ECOD είναι πλήρως ντετερμινιστικός, προσφέροντας σταθερά και επαναλήψιμα αποτελέσματα χωρίς αβεβαιότητες.
